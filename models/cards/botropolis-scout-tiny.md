# Model Card: botropolis-scout-tiny

## Model details
- Architecture: decoder-only transformer, trained from scratch (no base model)
- Size: 5,487,104 parameters (d_model 256, 6 layers, 4 heads, vocab 1397, word-level tokenizer)
- Trained for agent: Scout (research department, web research specialist)
- Training: 50 epochs on CPU, AdamW, next-token prediction. Best checkpoint kept by validation loss.
- Version / date: v0.1, trained 2026-09-30
- Weights: models/weights/botropolis-scout-tiny/model.pt (fp32, ~22MB), plus tokenizer.json, config.json, eval.json

## Intended use
Pipeline proof of concept. It exists to prove the Botropolis training loop
works end to end: dataset to tokenizer to training to checkpoint to eval to
registry. It is not intended for real use. Do not deploy it, do not trust
its answers.

## Training data
300 synthetic examples generated by training/make_scout_demo_dataset.py:
60 research topics x 5 question phrasings, answers hand-written in Scout's
voice. 90/10 train/val split. No user data, no scraped data. The data is
tiny and templated, which the eval numbers reflect.

## Evaluation
- Validation perplexity: 5.17 (val loss 1.6425). Honest caveat: the val set
  shares answer templates with the train set, so this number measures how
  well the model learned the format, not general quality.
- Sample generations (greedy decode, trimmed to the completion):

Note: fluent Scout-style prose, but the wrong topic (rerankers, not pgvector).

Note: wrong topic again (synthetic data, not LoRA), and the last sentence

## Limitations
It learns the shape of a Scout answer (confident tone, structured sentences,
date-aware phrasing) without reliably learning which facts go with which
topic. Small data plus small model means memorized templates and mixed-up
content. It will state wrong things fluently. English only.

## Ethical considerations
A model that sounds like a careful researcher while mixing up facts is
worse than one that sounds unsure. This card exists so nobody mistakes the
demo for a working model. The real path to a usable Scout fine-tune is
training/colab_lora.py on a free GPU with more data.

## How to run
Registered in models/registry.yaml as `botropolis-scout-tiny` (status:
trained). To regenerate samples locally:
`./.venv-train/bin/python -c` with torch, load model.pt via
training/train_scout_tiny.py's generate().

## Reproducing
1. `.venv-train/bin/python training/make_scout_demo_dataset.py`
2. `.venv-train/bin/python training/train_scout_tiny.py --epochs 50`
